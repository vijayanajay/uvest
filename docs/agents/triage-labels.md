## Triage Label Vocabulary
The repository uses the canonical triage roles for managing tickets in `docs/tickets/`:

- `needs-triage`: Newly submitted trade validation bug, missing metric, or feature idea.
- `needs-info`: Blocked on missing data feed, broker API contract, or market domain clarification.
- `ready-for-agent`: Fully specified and frozen ticket ready for automated TDD execution.
- `ready-for-human`: Requires manual review by senior human trader / quant.
- `wontfix`: Rejected trade setup, out-of-scope option strategy, or invalid proposal.
