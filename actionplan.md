## ▶ Next up (selected 2026-10-17)
**Stage 2's live Tier-1 daily-OHLCV fetcher — the item that stops the offline fixture trap.** It is picked
over the larger remaining blocks (stage 10's price half, stage 11) because it is the gate on *every*
other stage's evidence in production: one stock series feeds stages 2, 3, 4 and 8, so one cached fetch
is what turns four waivers into four measured blocks.

*Measured, not assumed.* Running the committed RELIANCE paste through `scripts/run_pipeline.py` with no
fixtures — its only live input `--regime-live` — waives **7 of the 8 upstream stages** (`out_2` … `out_8`
all `waived: true`) and computes the verdict from stage 1 alone: **7.11/20.0 (35.5%), P(win) 49.2%,
`GO_WEAK`**, i.e. a 20-point ceiling on a 100-point model and §10.4's 55% floor unreachable by
construction. Stage 4 names the cause itself (`ohlcv:absent, series:^CNXENERGY:absent`).

Two sub-gaps travel with it and are named here rather than discovered later:
- **Stage 7's live sector series is Yahoo-only** and returned nothing for `^CNXENERGY`, the sector of
  this very paste; stage 7 is all-or-nothing at the payload level (ADR-010 decision 3), so one absent
  sector series costs the whole 15-point macro block. The NSE daily index archive
  (`ind_close_all_DDMMYYYY.csv`) is already parsed for the training corpus
  ([tests/evals/build_index_corpus.py](tests/evals/build_index_corpus.py)) — the fallback is a reuse,
  not a new source.
- **No `data_cache/` caching exists yet** for either fetch, so every run refetches; the caching item
  beside the fetcher in §Stage 2 is part of the same change, not a follow-up.

### Blueprint 2: Stage 10 Price Stewardship & Adverse Movement Tracker (`TICK-011`)
*Builds the missing price-half of Stage 10 to protect live capital and enforce position stewardship.*

1. **Target File:** [scripts/10_daily_triage.py](file:///d:/Code/uvest/scripts/10_daily_triage.py)
2. **Missing Input Ingestion:**
   - Extend `--action triage` to read the position's latest market close/live price ($P_{\text{live}}$) and 14-period ATR from `data_cache/ohlcv/{SYMBOL}.json` or live fetcher.
3. **Operational Zone Classification:**
   - **Profit Harvesting Zone:** $P_{\text{live}} \ge \text{Target}_1$ or Gain $\ge 2.0\times\text{ATR}$. Action: Recommend trailing stop to $P_{\text{entry}} + 1.0\times\text{ATR}$.
   - **Healthy Runway Zone:** $P_{\text{live}} > P_{\text{entry}}$ and $P_{\text{live}} < \text{Target}_1$. Action: `HOLD`.
   - **Adverse Movement Zone:** $P_{\text{live}} < P_{\text{entry}}$. Calculate Drawdown in ATR: $\text{DD}_{\text{ATR}} = (P_{\text{entry}} - P_{\text{live}}) / \text{ATR}_{14}$.
   - **Time Stop Zone:** Days active $>12$ sessions without progress ($|P_{\text{live}} - P_{\text{entry}}| < 0.5\times\text{ATR}$). Action: `EXIT` before weekend carry decay for Futures.
4. **Deterministic Posterior Update Formula:**
   $$\Delta_{\text{drawdown}} = \begin{cases} 0\% & \text{if } \text{DD}_{\text{ATR}} \le 1.0 \\ 5\% & \text{if } 1.0 < \text{DD}_{\text{ATR}} \le 1.5 \\ 12\% & \text{if } \text{DD}_{\text{ATR}} > 1.5 \end{cases}$$
   $$\text{still\_chance\_pct} = \text{clamp}\left(P_{\text{prior}} + \sum \Delta_{\text{premise}} - \Delta_{\text{drawdown}}, 5\%, 95\%\right)$$
5. **Actionable Position Verdicts:**
   - `HOLD`: $\text{still\_chance\_pct} \ge 55\%$ and $\text{DD}_{\text{ATR}} \le 1.0$.
   - `PRESSURE`: $\text{still\_chance\_pct}$ drops $>15\text{pp}$ below entry prior or $<55\%$ for 2 consecutive sessions. Calculate `tighten_stop_to = max(hard_stop, P_live - 0.75 * ATR_14)`.
   - `EXIT`: $\text{DD}_{\text{ATR}} > 2.0$ or Macro Premise `LIQUIDATE` or $\text{still\_chance\_pct} < 40\%$. Calculate `soft_exit_zone = [P_live, P_live * 1.005]`.
6. **Golden Rule Invariant:**
   - If user inputs new buy order or query for an open trade with $P_{\text{live}} < P_{\text{entry}}$, raise fatal warning: `AVERAGING_DOWN_PROHIBITED`.
7. **Artifact Output:** Emit full payload matching BRD §11.3 schema to `out_10_triage.json`.

### Blueprint 3: Stage 11 Failure Autopsy Engine (`TICK-012`)
*Closes the continuous learning loop and implements self-calibrating rubric weights.*

3. **5-Category Failure Taxonomy Classifier:**
   - `VOLATILITY_NOISE`: Stoploss hit ($P_{\text{low}} \le \text{SL}$), but within 22 trading sessions, forward price reaches the original target price. (Diagnosis: SL was placed too tight, $<1.0\times\text{ATR}$).

4. **Deterministic Bayesian Weight Tuning Algorithm:**
   - Compute Brier score on resolved trades: $\text{Brier} = \frac{1}{N}\sum (P_{\text{win}, k} - y_k)^2$ where $y_k \in \{0, 1\}$.

     - If `VOLATILITY_NOISE` $\implies$ Increase Math module weight by $+0.5$, penalize tight stops.
     - If `REGIME_SHOCK` $\implies$ Increase Sector/Macro module weight by $+0.5$.
     - If `INSTITUTIONAL_DISTRIBUTION` $\implies$ Increase Flow module weight by $+0.5$.
     - Learning rate $\eta = 0.05$, bounds strictly constrained: no module may drift $> \pm 3.0$ pts from baseline.
5. **Database Persistence:**
